MySQL client benchmark — four micro-workloads by language

Per worker (work scales with worker count): bulk-insert single-int rows in 10-row prepared batches, fetch ints and sum in-app, insert 1 MiB blobs with in-app MD5, read blobs with in-app MD5. 13 languages, Percona Server 8.4.11 tuned for maximum write throughput (no per-commit disk sync), client and server on one 80-core host, workers 4 → 512, no pre-warming. All languages run on stock runtime defaults; enable Show optimized Go/C# to focus on Go and C# with their stock and tuned-runtime curves.

Throughput (blobs/s) per language, grouped by worker count (512 at top down to 4). Same colour and inner glyph per language as above.

Per-worker counts (work scales with worker count); barrier-synchronized timing; inserts run before the matching reads at each worker count; reads hit server-cached data (no warm-up). Client CPU = user+sys of the benchmark process tree; server CPU = mysqld utime+stime delta. Go and C# are run twice (stock and tuned runtime) and kept as separate benchmarks.
