MySQL client benchmark — throughput & CPU cost by language

sysbench oltp_read_write-style transactions (10 point selects, 4 range selects, 2 updates, delete+insert per txn), 10 M-row table, Percona Server 8.4.11, one language per pristine data load, 15-minute read-only sysbench warm-up before each sweep, client and server on the same 80-core host. Workers: 4 → 512. Work-based workload: every worker runs a fixed 10,000 transactions per rung. Go and C# use tuned runtime settings (Go GOMAXPROCS=16 GOGC=800; C# server GC); the other languages run on stock runtime defaults.
